# Code of Conduct

ZUnit follows the Z-Shell organization
[Code of Conduct](https://github.com/z-shell/.github/blob/main/.github/CODE_OF_CONDUCT.md).

Reports should use the contact channels listed on the
[Z-Shell organization profile](https://github.com/z-shell). This repository
keeps a local pointer so contributors can find the current organization-wide
policy without maintaining a divergent copy here.
